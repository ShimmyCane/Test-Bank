# CASP raw-chat review and summaries

I found the relevant prep steps in the project plan:
- Step 1: Review and sort raw JSONs inside CASp/Raw Chats whenever they mention CASP.
- Step 2: Compile the selected conversations and note the time plus a brief description.

I filtered the raw-export files by CASP references and reviewed them in batches below.

Saved outputs:
- Full raw-object extraction: selected_chats_full.json
- Flat list export: selected_chats_flat.json
- HTML review viewer: index.html
- These include both the direct CASP-related chats and adjacent architecture/testing chats that were marked relevant for study and code review.

To review the selected chats in the browser, open index.html in a local web server (for example: `python -m http.server 8000` from this folder, then visit `http://localhost:8000/`).

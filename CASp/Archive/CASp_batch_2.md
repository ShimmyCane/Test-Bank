# CASp Batch 2 — 60-Question Practice Set

This is the second batch of a CASp study bank. It continues the same emphasis on governing authority, scope, technical logic, and the distinction between standards, project facts, and legal trigger analysis.

## Section A — CBC / ADA / public accommodation and commercial facility analysis (24 questions)

### 1
When a technical requirement is in dispute, what is the first question to resolve?
A. Which authority and edition govern the project?
B. Which furniture style is shown in the plans?
C. What is the nearest coffee shop?

Explanation: The governing code sets the applicable standard and exceptions; technical review starts from the controlling authority and edition.

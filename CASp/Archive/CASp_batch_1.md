# CASp Batch 1 — 60-Question Practice Set

This is the first batch of a CASp study bank derived from the project materials and the supplied blueprint. It emphasizes governing authority, scoping logic, and the distinction between code framework, technical standards, and project facts.

## Section A — CBC / ADAAG public accommodation and commercial facility scoping and technical application (24 questions)

### 1
A retail tenant improvement is proposed in a commercial building. Before selecting the technical accessibility requirement, what is the most important first step?
A. Determine which standard governs the project and the adopted code edition.
B. Count the number of restrooms in the building.
C. Assume the ADA applies because the project is commercial.
D. Check whether the building has a website.
Answer: A
Explanation: The governing authority and edition must be identified before technical dimensions or fixture counts are applied. Facility type, project scope, and authority matter before answering technical questions.

### 2

B. It applies only to residential dwellings.
C. It replaces ADA requirements for all commercial projects.
D. It is only used for reporting and not design review.
Answer: A
Explanation: Chapter 11B is a core California accessibility code that includes both applicability and technical requirements.

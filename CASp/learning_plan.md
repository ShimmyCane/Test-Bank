# CASp Learning Plan

## Purpose
Create a focused, exam-ready study and question-bank workflow for CASp preparation using the selected chat materials, code framework notes, and verified accessibility truths. The goal is not memorization alone, but learning to identify the governing authority, project facts, and correct code/application before selecting the answer.

## Target outcome
- Build a compact but high-yield CASp review plan for the next study cycle.
- Generate a question bank aligned to the code categories and exam blueprint.
- Separate confirmed legal/code facts from user recollection or assistant speculation.
- Train for rapid identification of the standard, code section, and project conditions.

## Key study goal
- Date: 10/1/26
- Exam/review date: 10/2/26
- Goal: last-minute review of mastery for the major CASp accessibility topics and test-bank patterns.

## Core learning objectives

### 1. Governing standards
Master the distinction between:
- CBC Chapter 11B
- CBC Chapter 11A
- ADA Title II and Title III
- Section 504
- FHA / Fair Housing Act
- California-specific statutory and CASp-program requirements

Focus: identify which authority applies before answering any technical question.

### 2. Scoping and applicability
Be able to quickly determine:
- facility type and occupancy/use
- new construction vs alteration vs addition
- public accommodation vs housing vs government facility
- whether the project is subject to CBC, ADA, FHA, or another authority
- whether project facts trigger path-of-travel or other alteration obligations

### 3. Technical application
Review and practice the most common high-value technical areas:
- accessible routes and site circulation
- accessible parking and van-accessible parking
- doors, thresholds, clear openings, and maneuvering clearances
- toilet room and plumbing accessibility
- elevators and lobby requirements
- signage, thresholds, and general elements

### 4. California-specific and CASp responsibilities
Study the link between:
- CASp program responsibilities
- California statutory disability access requirements
- Civil Code, Government Code, and Health & Safety Code references
- reporting, project review, and field-observation expectations

### 5. Test-bank construction
Create a reusable question-bank format that teaches the logic, not merely the answer.

## Study approach

### Priority order
1. Standards identification and authority selection
2. Scoping questions (what rule applies and why)
3. Route and parking technical questions
4. Door/element/plumbing questions
5. Housing comparisons and federal law overlap
6. California law / CASp responsibility / inspection reporting

## Question and answer format

### Question format rules
- Use multiple-choice format for the main bank.
- 50% of questions should be longer scenario-based items with 3+ sentences. Reference the matrix: owner type, use type, funding source, elevator vs/ no elevator, etc... Be specific with these questions/ scenarios.
- 50% of questions will have single-sentence application answers.
- Every question should force the learner to identify the governing authority, project facts, or code section.
- Include distractors rooted in common mistakes:
  - wrong agency
  - wrong facility type
  - wrong code edition
  - wrong scoping trigger
  - wrong technical interpretation

### Answer format rules
- Format: multiple choice only.
- Answers to include slightly longer explanation-driven choices when needed.
- Correct answers must match the controlling authority and project facts.
- Don't have multiple questions have the same type answers

### Explanation format
- Keep explanations simple and direct.
- State the governing standard.
- Name the key fact that triggers the rule.
- Explain any wrong traps in plain language.
- Separate the legal application from the technical result.

### Difficulty scale
- 1 = basic recall
- 2 = straightforward application
- 3 = moderate case analysis
- 4 = multi-step project review
- 5 = hardest scenario-based exam style question

## Weekly study rhythm

### Phase 1: Foundation review
- Review CBC 11B, 11A, ADA, FHA, and Section 504 framework
- Identify project-type triggers and distinctions
- Capture the legal authority before dimensions

### Phase 2: Scenario drills
- Work through 10–15 scenario questions per category
- Focus on why the answer is correct, not just what the selected option says
- Correct wrong assumptions and record recurring traps

### Phase 3: Mixed-format bank review
- Review both long-form scenario questions and short direct questions
- Re-test missed concepts in new wording
- Rebuild explanations around authority + fact + technical rule

### Phase 4: Final mastery pass
- Run timed mixed-category sets
- Identify weak areas by category
- Final pass should emphasize rapid rule selection and confident explanation

## Success criteria
The learning plan is successful when the learner can do the following without hesitation:
- state which code or law governs a project
- explain why the authority applies
- distinguish technical rules from project-scope rules
- spot the common traps in parking, routes, doors, housing, and federal overlap
- explain the answer in plain language using the right standard and facts

## Final note
This plan is designed to make the question bank useful for both exam prep and real-world decision-making. The key rule for every item is simple: identify the governing standard first, then answer the technical question.

High-level overview

This file is the shared, client-side quiz experience. It loads and validates JSON banks, lets learners choose one or more banks, presents timed questions and explanations, tracks attempts and flags, and reports results by category and subcategory. Banks may provide a shared passage or a list of passages referenced by question; the app displays the relevant text and, when read-aloud is enabled, speaks that passage before the question and answer choices.

Key responsibilities

  • Defines the responsive visual theme and touch-friendly quiz layout.
  • Loads and validates question JSON files, including shared passages and passage lists linked by passage_id.
  • Starts with the three featured Reader Level L banks; “Show all test banks” reveals expandable topic groups.
  • Reads a passage before its question and answer choices when read-aloud is enabled; passage-free questions retain the existing behavior.
  • Tracks selected banks, timing, attempts, flags, and progress; shows explanations and reports results by category.
  • Includes CASp banks and seven original Reader Level L practice banks; these are not official F&P assessments.
